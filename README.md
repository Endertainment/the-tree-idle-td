# The Tree: Idle Tower Defense

A portrait mobile tower-defense / idle game for Godot 4. Corrupted creatures march along two winding roads toward a colossal Life Tree. The tree fights back, guardian units sit on its branches, and eight ancient pedestals around it can hold towers. Waves get harder, the tree eventually falls, and permanent upgrades make the next run stronger.

**Status:** pre-alpha. The repository currently contains the Godot project scaffold, the approved UI references and the full build specification. Implementation starts at Milestone 0.

## Quick start

1. Install Godot 4.x (version matching `project.godot` → `config/features`).
2. Open `project.godot` in the editor. The project targets `1080x1920` portrait, mobile renderer.
3. Press `F5`. Right now you get the placeholder main menu.

## Working with an AI agent

The spec is big on purpose (~24k tokens). Do not paste it into a chat and do not let an agent read it whole every time.

1. `AGENTS.md` — the protocol: read order, context rules, session loop, verification, commits.
2. `docs/PROGRESS.md` — where we are; read first in every session, updated at the end.
3. `docs/milestones/M0.md` … `M8.md` — one brief per session, listing the exact spec sections to read.

Boot prompt for a fresh session lives at the end of `AGENTS.md`. One session = one milestone; a red check blocks progress; unfinished work ends with a handoff block, not with a longer chat.

## Planned structure

```
scenes/     screens and battle entities
scripts/    autoloads, battle, combat, data, progression, economy, ui, platform, util
data/       .tres content: enemies, towers, units, waves, cards, upgrades, maps
ui/         theme, reusable components, shaders
assets/     art, audio, fonts (placeholders generated by tools/)
config/     env, monetization, shop catalog
localization/strings.csv (en, uk)
tools/      placeholder generators, layout validator, balance simulator
tests/      headless test runner
server/     FastAPI + Neon backend (Milestone 7)
```

## Tooling

- Engine: Godot 4.x, GDScript (typed), mobile renderer.
- Test device: LDPlayer (Android x86_64). Real-device testing recommended before release.
- Platform services: AdMob (rewarded + interstitial), Google Play Billing. Both are wrapped by services with desktop stubs, so the game always runs in the editor.
- Backend: FastAPI + PostgreSQL (Neon), added in Milestone 7. The client is local-first and fully playable offline.

## Git

- `main` is the stable branch; work happens on `feat/mN-*` branches.
- Conventional Commits, e.g. `feat(battle): add wave manager`.
- Tags per milestone: `v0.1.0-m1` … `v1.0.0-m8`.
- `.godot/`, `android/`, builds and signing keys are ignored. Commit `.import` files.
