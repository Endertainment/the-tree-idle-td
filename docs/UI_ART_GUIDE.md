# UI art guide — how a texture becomes a widget

Practical rules for replacing the placeholder art in `assets/art/`. Every asset
is a separate file with a fixed size; the theme (`ui/theme/main_theme.tres`,
generated by `ui/theme/theme_builder.gd`) is the only place that maps a file to
a widget. Change the PNG, keep the path — no code changes.

## 1. Nine-slice in one paragraph

A 9-slice texture is stretched in the middle only. `texture_margin_*` in the
theme says how many pixels of each edge must never stretch (the "caps" and the
"corners"); `content_margin_*` is the padding inside the widget. If the art has
a 60 px wooden frame, the margins are 60 — otherwise the frame smears.
The margin values live in `theme_builder.gd` next to the file path.

## 2. Top bar

| | |
|---|---|
| File (menu) | `assets/art/ui/menu/top_bar_9p.png` |
| Design size | 890×149, drawn as a full-width bar ~130 px tall |
| 9-slice | 64 / 52 / 64 / 52 (thick leaves on the sides) |
| Content margins | 72 horizontal, 18 vertical |

The menu bar is used by **all** meta screens (Home, Workshop, Cards, Missions,
Shop, Profile, Leaderboard, Magica) through the `TopBar` theme variation, so the
padding is identical everywhere — do not add per-screen margins.

Battle has its own bar and its own file:

| | |
|---|---|
| File (battle) | `assets/art/battle/hud/top_bar_battle_9p.png` |
| 9-slice | 24 / 24 / 24 / 24 |
| Content margins | 28 / 16 |

Keep the two independent: the battle bar is tighter, has no leaves and carries
speed buttons and two currency pills.

## 3. Round avatar inside a frame

- Frame art: square PNG, transparent centre, ring on top (`profile_frame.png`).
- Avatar art: square PNG, at least 256×256, **no** rounding needed.
- The `Avatar` node uses `ui/shaders/circle_mask.gdshader`, stretches with
  `KEEP_ASPECT_COVERED` and is inset 8 px inside the frame.

Result: the avatar is cropped to a circle and scaled to fill, like a profile
picture. To change the crop, edit `radius` / `center` on the material; to move
the avatar deeper into the ring, change the 8 px inset in `main_menu.tscn`.

## 4. Rounded XP bar (and any pill-shaped progress bar)

Two files, both 400×32:

| File | Purpose |
|---|---|
| `assets/art/ui/menu/xp_bar_bg.png` | empty track, rounded corners, radius **16** |
| `assets/art/ui/menu/xp_bar_fill.png` | fill, rounded corners, radius **16** |

How to draw: a capsule — height 32, corner radius = height / 2 = 16. The fill
must be the same capsule, not a rectangle, otherwise the left cap is square.

How it works: the theme registers the `XpBar` variation with 9-slice margins of
16 on all sides. The left 16 px and the right 16 px of the fill never stretch;
only the middle does. That is why the ends stay round at any progress value.

Rules:

- Do not scale the bar vertically. The caps are fixed 16 px, so the control
  height must stay 32 (`custom_minimum_size` in `main_menu.tscn`). A 26 px bar
  squashes the caps.
- Do not draw a separate "empty" version of the fill — the track shows through.
- If you need a thicker bar, redraw both files at e.g. 400×48 and set the
  margins to 24 in `theme_builder.gd`, then update the control height.

The node `BattlePanel` in `main_menu.tscn` already uses the variation. If the
panel looks like a plain rectangle, the theme was not regenerated after the art
was added:

```powershell
& 'C:\Tools\godot-4.7.2\Godot_v4.7.2-stable_win64.exe' --headless --path . --script res://ui/theme/theme_builder.gd
```

## 6. Fonts

`assets/fonts/Alegreya-ExtraBold.ttf` (display) and `Alegreya-Bold.ttf` (body)
are wired by `theme_builder.gd`. Both faces must contain Cyrillic: check `ї`,
`і`, `є`, `ґ` before shipping. If a font file is missing, the theme falls back
to the engine default instead of failing.

## 7. Checklist before committing art

1. Same file path, same pixel size as `docs/ART_MANIFEST.md`.
2. No baked-in text on generic panels — text is localised and drawn on top.
3. Transparent background, no white halo on the edges.
4. 9-slice caps are uniform: the corners must look right when the panel is
   stretched to any width.
5. Regenerate the theme, run `tools/check_project.ps1`, open the screen at
   1080×1920 and at 1220×2712 (tall phone) before pushing.
