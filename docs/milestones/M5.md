**Goal:** the game looks and sounds like a product (with placeholders): menu per reference, navigation, settings, onboarding, shop/leaderboard UI, full uk/en text.
**Depends on:** M4 tagged `v0.5.0-m4`.
**Sessions:** 2–3.

## Tasks

- [ ] Main menu per `docs/reference/ui_main_menu.png`: top bar, logo, stats card, Battle CTA, speed trial, daily card, 5-tab nav.
- [ ] `SceneRouter` transitions (fade), back stack, Android back button behaviour.
- [ ] Settings: audio sliders, language, text scale, haptics, shake, FPS counter (debug).
- [ ] Onboarding: language → nickname + avatar → play; validation; stored profile.
- [ ] Workshop / Magica / Cards / Missions screens using the M4 services.

- [ ] `strings.csv` with all keys, uk + en; `LocaleService` formatting + Ukrainian plurals.
- [ ] `AudioService`: music crossfade, SFX pool, bus volumes; hook every event from §9.9.
- [ ] Toasts, modals, loading and empty states, notification dots.

## Acceptance

- [ ] Every screen reachable and back-navigable; no dead ends.
- [ ] Language switch is instant and complete; key-extractor test passes (no missing keys, no unused leftovers).
- [ ] No `ColorRect` masquerading as UI; every visual is a manifest asset.
- [ ] Audio settings persist across restarts; music does not restart on screen change.
- [ ] Layout survives +30 % string length (pseudo-locale) and 4:3 / 19.5:9.

## Watch out

- Do not "improve" the reference layout — it is approved.
- Strings only through `tr()`; no concatenation of sentences.
- Keep the menu scene under ~400 lines by extracting components, not by adding one more `if`.

Screens done, missing keys count, placeholder assets used, next command.
