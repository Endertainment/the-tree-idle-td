## Acceptance

- [ ] Zero errors and zero warnings in the console on boot.
- [ ] Generator reports `created = total, failed = 0`; every manifest path exists on disk.
- [ ] F5 → menu → battle → back works without errors.
- [ ] `tools/check_project.ps1` green; `tests/run_tests.gd` green.
- [ ] `docs/ART_MANIFEST.md` generated from the JSON (not hand-written).

## Watch out

- Do not implement gameplay-sounding stubs (no fake waves, no fake economy). Empty scenes are fine at M0.
- Keep placeholders tiny (flat color PNG, < 5 KB). 240 files must stay under ~1 MB total.
- `SceneRouter` must be the only place that calls `change_scene_to_file`.
- Autoloads must not `await` network/plugin calls during boot.
