**Goal:** the full launch combat vocabulary: 4 enemies, 4 towers with tiers, 3 guardian units on the tree, crit/armor/slow, bosses.
**Depends on:** M1 tagged `v0.2.0-m1`.
**Sessions:** 2–3.

- [ ] Every tower and unit buildable and upgradable to L10; stats match spec §4.5 within rounding.
- [ ] Crit and slow visibly correct; unit test covers armor floor and crit math.
- [ ] 120 enemies + 8 towers + 4 units ≥ 55 FPS on LDPlayer; draw calls < 120.
- [ ] Boss appears at 10/20/30 with bar + banner; killing it grants the right cash.
- [ ] Memory flat over a 20-minute session (no node/projectile leak).

## Watch out

- No `if tower_id == "cannon"` in gameplay code — behaviors and stats come from data.
- Projectiles must not be physics bodies if a distance check is enough.
- Do not add new UI screens in M2; tower/unit sheets belong to M3.
