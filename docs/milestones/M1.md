# M1 — Battle vertical slice

**Goal:** one playable run — ugly but correct. Player can start a run, build one tower type, survive some waves, lose, get coins, return to the menu.
**Depends on:** M0 done and tagged `v0.1.0-m0`.
**Sessions:** 2–3.

## Read (spec)

- §4.1 Arena layout, §4.2 Lanes, §4.3 Pedestals, §4.4 Tree (stats only), §4.8 Waves, §4.9 Run end
- §4.10 In-run economy (cash only, no upgrade panel yet)
- §11.2 Scene composition
- §11.5 `EnemyData` / `TowerData` / `WaveTable`
- §13.4 Battle HUD (minimum: wave, cash, tree HP, Upgrade button)
- §14.1 Automated checks

## Tasks

- [ ] `MapData` resource + `forest_clearing.tres` with two lanes, 8 pedestal positions, 4 unit-slot anchors.
- [ ] `BattleController` + `BattleClock` (sim speed hook, not `Engine.time_scale`), `WaveManager`, `Spawner`.
- [ ] `Enemy` scene: `PathFollow2D`, speed, HP, leak damage, cash reward, death.
- [ ] `Tree`: HP, auto-attack (single target, homing projectile), leak handling, defeat.
- [ ] `Pedestal` ×8: empty / selected / occupied; build Archer Tower; sell (70 % refund).
- [ ] `Tower` scene: acquisition, firing, projectile, damage via `DamageResolver`.
- [ ] Wave table for waves 1–10 with `grunt` only, hp multiplier `1.16^(w-1)`.
- [ ] Battle HUD minimum + wave banner + 6 s countdown with "next wave" button.
- [ ] `RunSummary` with coin payout, granted once; back to menu.

## Acceptance

- [ ] A full run can be started and lost; summary grants coins exactly once.
- [ ] Enemies follow both curves smoothly (no jitter, no corner snapping).
- [ ] Cash math matches spec: kill reward and wave clear bonus.
- [ ] 40 enemies + 3 towers at 60 FPS on LDPlayer.
- [ ] No orphaned nodes after 10 minutes of play (debug overlay counts stable).

## Watch out

- Path must not cross a pedestal (run `tools/validate_layout.gd`, even if it is rough at this stage).
- One damage path only: `DamageResolver`. No `enemy.hp -= dmg` anywhere else.
- The run must be fully data-driven: changing wave 3 in the `.tres` changes the game.
- No upgrade panel yet — but leave the button wired to a placeholder sheet.

## Report

Wave reached by the bot/manual play, FPS numbers, files, next command.
