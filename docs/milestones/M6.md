**Goal:** a real APK on LDPlayer with working rewarded ads, test purchases and analytics — while the editor still runs everything through stubs.
**Depends on:** M5 tagged `v0.6.0-m5`.
**Sessions:** 2–3 (plugin version checks can eat a session — timebox them).

## Acceptance

- [ ] `adb install` → app runs 60 FPS on LDPlayer; back button behaves per §14.2.
- [ ] Rewarded ad grants exactly one reward, survives app kill mid-ad, failure path shows a toast.
- [ ] Test purchase grants once; reinstall + restore recovers entitlements.
- [ ] Works with Play Services disabled (graceful "store unavailable").
- [ ] No production IDs, keys or keystores in git.

## Watch out

- `OS.has_feature("android")` only inside adapters.
- Do not block boot on ad SDK init.
- If a plugin is incompatible, ship the stub and write a decision entry — do not hack a fork.
